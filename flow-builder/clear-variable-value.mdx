title: "Borrar valor de variable"
description: "Cómo vaciar el valor de uno, varios, o todos los campos personalizados de un usuario"
icon: "eraser"
---

Dentro de **Acciones básicas** tienes tres formas de vaciar valores de campos personalizados, según cuántos quieras borrar.

## Borrar valor de variable

Borra el valor de un solo campo personalizado. Simplemente selecciona el campo que quieres vaciar.

<Frame caption="Selección del campo personalizado a vaciar">
  <img src="/images/flow-builder/clear-variable-value-1.png" alt="Selección del campo personalizado a vaciar" />
</Frame>

## Borrar múltiples valores de variable

Borra el valor de varios campos personalizados a la vez. Selecciona todos los campos cuyo valor quieres vaciar.

<Frame caption="Selección de varios campos personalizados a vaciar">
  <img src="/images/flow-builder/clear-variable-value-2.png" alt="Selección de varios campos personalizados a vaciar" />
</Frame>

## Borrar todos los campos personalizados del usuario

Si necesitas vaciar absolutamente todos los campos personalizados de un usuario de una sola vez, usa esta acción.

  <img src="/images/flow-builder/clear-variable-value-3.png" alt="Confirmación para vaciar todos los campos personalizados del usuario" />
</Frame>
