**JSON** es también un tipo de variable. Se usa para guardar y administrar una serie de datos, incluyendo tanto variables normales como otras variables de tipo JSON. Por ejemplo, un JSON puede guardar los datos completos de un cliente en un solo lugar.

  <img src="/images/flow-builder/json-operation-1.png" alt="Ejemplo de una variable JSON guardando los datos de un cliente" />
</Frame>

La opción **Operación JSON** vive dentro de **Acciones básicas**, en el nodo de Acción.

<Card type="tip">
  Ya hay varios ejemplos incluidos directamente en cada operación — selecciona una operación y usa el botón **Ejemplos** para explorarla.
</Card>
